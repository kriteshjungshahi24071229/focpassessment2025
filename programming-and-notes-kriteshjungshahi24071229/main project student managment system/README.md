This project is a console-based Student Management System developed using Python.
It allows basic management of student records using text files and provides separate functionalities for Admin and Student users.
The system is designed using concepts taught in class such as functions, classes, file handling, loops, and conditional statements.

# Features:

# Admin
Add new users (students or admins)
Modify existing user details
Delete users
Enter or update student grades
View average grades for each subject

# Student
View personal grades
View ECA (Extra-Curricular Activities) participation
Update personal profile information
File Storage

The program uses simple text files to store data persistently:
users.txt — stores user ID, name, and role
passwords.txt — stores login credentials
grades.txt — stores student grades
eca.txt — stores ECA participation records

# How to Run the Program
Ensure Python 3.x is installed on your system
Open a terminal or command prompt
Run the program using:
python <filename>.py
