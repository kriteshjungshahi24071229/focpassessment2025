# This here is the final look to my flask web application. Initially started just as a simple "Hello World" program.

# Key Features
* Template Inheritance: I Used a base.html skeleton to keep the design consistent across all the pages.

* User Authentication: A login/logout system using Flask Sessions.

* Role-Based Access: Admins can add, delete, and clear the favorites list as desired.

* Students can only view and sort the list.

* Dynamic Logic: Uses Python functions to handle string operations (reversing/uppercase) and list management.

* Styling: Custom CSS located in the static/ folder for a clean UI.

# How to Run 
Navigate to the project folder: cd flask_hello_app
Activate the environment: venv\Scripts\activate
Install dependencies: pip install flask (if not already installed)
Run: python app.py
Access: Open http://127.0.0.1:5000 in your browser.
